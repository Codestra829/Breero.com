# @breero/ui

Shared BREERO design-system package.

Planned primitives: buttons, inputs, select, textarea, dialog, drawer, sheet, cards, badges, avatars, tables, tabs, breadcrumbs, pagination, date picker, time-slot picker, address input, money display, status badges, timelines, map wrappers, loading/empty/error states.

Public marketplace and internal portals share primitives but may use different composed layouts.
