# BREERO Partner Portal

Target: `partners.breero.com`

Owns vendor and technician workflows:

- job offers
- accept/decline
- worker assignment
- on-my-way / arrive / start / diagnostic / complete commands
- work requests
- workers
- availability
- earnings and payouts
- company profile and documents

Frontend implementation: Next.js + TypeScript using shared `packages/ui` and `packages/api-client`.
