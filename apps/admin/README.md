# BREERO Admin & Finance Portal

Target: `admin.breero.com`

Owns:

- users, roles and permissions
- legal entities and service areas
- service catalog, questions and pricing
- vendor approvals and documents
- payments and refunds
- vendor earnings and payout batches
- audit logs, integrations and system settings

Finance-sensitive actions require dedicated permissions (`FINANCE` / `SUPER_ADMIN` as configured).
