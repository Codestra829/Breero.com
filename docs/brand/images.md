# Image system

Runtime images live under `apps/web/public/images/`. Components read paths from
`apps/web/content/images.ts`; the checklist is `content/image-manifest.json`.

The 32 core slots use 2400×1600 targets for heroes and 1600×1200 for cards. Current WebP files are
generated editorial drafts and must not be represented as real BREERO staff or customers. Replace
with consented final photography using the same filenames. Use natural daylight, attainable
European homes, authentic working moments and restrained blue accents. Avoid logos and embedded
text. Alt text describes the meaningful scene, not visual decoration.
