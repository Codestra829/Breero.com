# Colors

| Token | Value | Use |
|---|---|---|
| Blue | `#146EF5` | Primary action and links |
| Blue dark | `#0E52C6` | Hover and strong emphasis |
| Navy | `#0B1F3A` | Footer and premium dark surfaces |
| Ink | `#10243E` | Body and headings |
| Teal | `#18B7A0` | Trust and positive highlights |
| Teal dark | `#0F8C7A` | Accessible teal text |
| Coral | `#FF6B6B` | Small warm accents only |
| Yellow | `#FFC857` | Small friendly highlights only |
| Sky | `#EAF4FF` | Cool sections |
| Mint | `#EAFBF7` | Trust chips and positive backgrounds |
| Cream | `#FFF8EC` | Warm sections |
| Light gray | `#F5F7FA` | Neutral canvas |
| Mid gray | `#66768A` | Secondary copy |
| Border | `#DCE4EC` | Dividers and card borders |

Never use coral or yellow for long copy. Tokens live in `apps/web/app/brand.css`.
